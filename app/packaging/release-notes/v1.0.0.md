# WinShot 1.0.0

Status: Engineering draft
Release date: Unscheduled

## Highlights
- Capture an area, window, display, or all connected displays through the resident tray workflow.
- Annotate, copy, save, pin, and review captures locally with user-controlled History retention.
- Record a selected region or display to local MP4, with optional audio and bounded local GIF conversion.

## Reliability and privacy
- Closing the dashboard keeps the resident tray process available until the user chooses Quit.
- Capture, OCR, recording, and conversion data remain local; no capture-content upload is implemented.
- Recovery and diagnostic paths use bounded, privacy-conscious local state.

## Known limitations
- No customer installer, automatic updater, or public download is available from this engineering draft.
- Recording depends on supported Windows media components, drivers, and the Visual C++ x64 runtime.
- Protected, elevated, DRM, and application-specific scrolling content may not be capturable.
