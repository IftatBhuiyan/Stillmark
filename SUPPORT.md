# Support

Stillmark is free and maintained by Iftat Bhuiyan with community contributions.
For reproducible bugs and feature requests, use GitHub Issues. For usage questions, use Discussions.
Support is best effort; a donation does not buy a response deadline or a feature commitment.

Existing commercial customers should retain their original installer and license records.
New open-source releases require no activation. The former commercial service and its customer
data are maintained separately during migration; do not post personal order details in GitHub.

GitHub Sponsors enrollment is pending. There is currently no active donation checkout.
When a verified funding destination is enabled, donations will be optional and all features remain free.
