Get help

Ask a usage question or report a reproducible bug. Include your app and operating-system versions. Keep captures and personal information out of public reports.

Make it better

Read the contribution guide, submit a pull request, or fork the project under GPLv3.

Optional donations

GitHub Sponsors enrollment is pending. There is no active donation checkout yet. Donations will never unlock features or be required to use Stillmark. Support is best effort, without a guaranteed response time.

Security

Report a vulnerability privately. Do not post credentials or sensitive screenshots in an issue.

Existing customers

Keep your original installer and license records. For private purchase questions, contact support@getstillmark.com. New open-source builds do not need your old key.
