# Stillmark website

A static, free-software website. No commerce, account client, API key, or build dependency.

Run `npm run check` to validate local links and publication boundaries. Run `npm run dev` for a local preview.
Deploy only HTML, CSS, site.js, and assets. Never deploy the monorepo root or the legacy backend.
Download links resolve through the official GitHub Releases; assets must exist before calling a release ready.
The desired Eclipse Studios subdomain is pending domain ownership and DNS verification.
